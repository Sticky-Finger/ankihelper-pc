# Changelog

本项目所有重要变更都会记录在本文件中。

## [v0.0.1] - 首个公开发布版本

Anki划词助手是一款将剪贴板中的英文句子智能切分为单词块，帮助快速生成 Anki 单词卡片的桌面效率工具。

### ⚠️ 注意：释义需手动填写

当前版本（v0.0.1）**未接入任何词典查询服务**，选中单词后**不会自动获取音标和释义**。要完成一张卡片，你需要：

- 选中目标单词后，**自行在其他词典应用/网站查询释义**
- 把查到的音标、词性、释义等内容**手动填写**到结果列表的对应字段
- 确认无误后，通过「添加」按钮写入 Anki

其余字段（单词、例句、例句翻译、发音 URL）会由应用自动填充，仍可手动修改。

> 词典自动查询（本地 .txt 词典 / 云端词典 API）已列入后续规划，详见 `docs/PRD.md`。

### ✨ 新功能

#### 核心流程
- **剪贴板智能解析**：实时监听系统剪贴板，将复制的英文句子自动切分为单词块；支持单击选中、Shift+单击连续多选组合成词组
- **原文编辑与锁定**：原文区域可直接手动编辑（编辑时自动暂停剪贴板监听）；支持 🔒 锁定原文，防止翻译复制等操作覆盖原文
- **智能分词引擎**：对英文句子按空格、标点等规则进行拆分，标点块以灰色样式区分
- **一键制卡**：通过 AnkiConnect 本地接口直接生成 Anki 卡片，例句中选中的单词用 `<b>` 标签自动高亮

#### AnkiConnect 集成
- **基础连接**：自动检测 AnkiConnect（`localhost:8765`）连接状态，状态栏实时反馈
- **牌组选择器**：药丸形容器 + 可搜索下拉列表，从 AnkiConnect 拉取牌组，添加卡片时使用用户选中的牌组
- **卡片模板管理**：支持导入 `.html` 模板文件（4 段 `@@@` 分隔：正面/背面/CSS/字段名），内置「划词助手Antimoon模板」
- **字段映射**：导入模板后可配置 UI 数据源（单词/例句/例句翻译/发音/空）→ 模板字段的映射关系，映射配置随模板持久化
- **模板增删**：用户导入的模板可删除（内置模板不可删），重启应用后自动恢复已导入的模板与字段映射

#### 词典与发音
- **手动添加（兜底）**：无需任何词典即可使用，选中词实时同步到结果列表，可手动编辑所有字段后添加
- **多发音源支持**：内置有道英音/美音发音源（不可删除），支持用户自定义新增发音源；应用内可试听（无选中词时用 "test" 测试）；字段映射编辑器支持「发音」数据源

#### 翻译服务
- **多翻译 API**：支持百度翻译 API / 有道智云 API，可在设置面板中配置
- **异步翻译**：剪贴板变化时不阻塞分词与查询流程，翻译字段支持手动编辑
