# Anki划词助手 产品需求文档 (PRD) – V1.0
> **设计原型**：本产品的 UI 高保真原型位于同级文件
  `anki-word-helper.html`，基于 Fluent 2 Design
  系统，支持亮色/暗色双主题预览。可通过 Open Design MCP 拉取源码。
## 1. 产品定位（一句话）

Anki划词助手是一款将剪贴板中的英文句子智能切分为单词块，结合本地词典查询快速生成 Anki 单词卡片的桌面效率工具。

## 2. 用户故事（核心场景）

**场景1：阅读英文文章时快速积累生词**
- 在浏览器或 PDF 阅读器中看到一段英文，复制句子
- 应用自动切分单词，选中生词后查询词典
- 一键添加到 Anki，无需手动编辑卡片

**场景2：批量处理多词查询**
- 句子中有多个不认识的单词
- 通过 Shift+单击连续选中多个单词形成词组
- 每个单词分别查询并独立添加卡片
- 例句字段自动填入原文并高亮选中的单词

**场景3：离线环境下的制卡**
- 在无网络的环境下阅读英文资料
- 依赖本地导入的 .txt 词典完成单词查询
- 翻译功能暂不可用，但制卡流程不受影响

## 5. 核心流程图

```mermaid
graph TD
    A[用户复制英文句子] --> B[剪贴板监听器捕获文本];
    B --> C[异步调用翻译 API 获取例句翻译];
    B --> D[分词引擎切分为单词块];
    D --> E[界面展示单词块];
    E --> F[用户点击/Shift+单击选择单词块];
    F --> G{防抖 300ms};
    G --> H[自动查询当前选中词典<br/>（支持手动/云端/本地）];
    H --> I{查询结果};
    I -->|成功| J[展示结果列表: 空条目 + 释义条目];
    I -->|超时/失败| K[展示结果列表: 仅空条目 + 提示];

    K --> L;
    L -->|点击添加| M[通过 AnkiConnect 添加卡片];
    L -->|点击预览| N[打开预览编辑弹窗];
```

## 6. 卡片字段定义与字段映射

### 6.1 UI 数据源字段

这些是应用界面上可提供给模板的字段值：

| 数据源 | 对应 UI 区域 | 说明 |
|--------|-------------|------|
| `单词` | 当前选中词组 | 用户选中的单词/词组文本 |
| `例句` | 剪贴板原文 | 剪贴板捕获的英文原文（手动编辑时可修改） |
| `例句翻译` | 原文翻译 | 翻译 API 返回的中文翻译（手动编辑时可修改） |
| `空` | — | 空字符串，用于不需要预填充的模板字段 |

### 6.2 字段映射

用户导入的模板包含自己的字段名列表（例如 `vocabulary_card_model.html` 的模板字段为：单词、音标、发音、例句、释义、例句翻译、url）。通过**字段映射**配置，将 UI 数据源映射到模板字段，用于添加卡片时预填充初始值。

- 导入模板后默认映射：**第一个模板字段 → `单词`，其余模板字段 → `空`**
- 用户可在设置弹窗中修改映射：每个模板字段对应一个 Select 选择器（选项：单词、例句、例句翻译、空）
- 显示格式：`<模板字段名> ← <数据源>`
- 映射配置随模板持久化（存 SharedPreferences），下次选择该模板时继续生效
- 预览编辑时所有字段值可被用户修改，映射只负责初始预填充
