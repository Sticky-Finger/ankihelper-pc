# 可导入配置的anki卡片模板文件——【以vocabulary_card_model.html为例】

## 根据这个模板添加出来的卡片效果

- 卡片编辑时，字段从上到下是——单词、音标、发音、例句、释义、例句翻译、url
- 卡片显示时，从上到下从左到右排是这个顺序——单词、音标、发音、例句、释义、例句翻译。卡片显示时是看不到url字段的

## anki卡片模板文件说明


```html
[正面模板代码]

@@@

[反面模板代码]

@@@

[样式 CSS]

@@@

[anki模板要创建的字段名，按顺序一行一个字段排列]
```

其中模板文件中独占一行的 `@@@` 是分隔符
