⏺ 根据搜索结果，我找到了一个可行的无登录方案。但需要注意一个重要问题：

  API 方案分析

  ❌ 有道免费公开 API

  - 已停止服务（2023年停用）
  - 现在必须使用有道智云付费服务

  ✅ 替代方案：Free Dictionary API

  - 官网: dictionaryapi.dev (https://dictionaryapi.dev/)
  - 无需认证，完全免费
  - 提供字段:
    - phonetic: IPA 音标（如 "həˈləʊ"）
    - meanings: 英文释义列表

  API 示例:
  GET https://api.dictionaryapi.dev/api/v2/entries/en/hello

  响应格式:
  [{
    "word": "hello",
    "phonetic": "həˈləʊ",
    "meanings": [{
      "partOfSpeech": "exclamation",
      "definitions": [{
        "definition": "Used as a greeting or to begin a phone conversation."
      }]
    }]
  }]

  ⚠️ 问题：中文释义

  Free Dictionary API 只提供英文释义。要获得中文释义，我们需要：

  推荐方案：API 组合
  1. 音标: Free Dictionary API（无登录）
  2. 释义: Free Dictionary API 获取英文释义 → 复用现有翻译服务翻译成中文

  这样的优势：
  - 无需额外 API 密钥
  - 复用已有的翻译配置
  - 音标和中文释义都能获得

  有道词典 API 关键信息

  接口地址

  https://openapi.youdao.com/v2/dict

  请求参数

  ┌──────────┬───────────────────────────┐
  │   参数   │           说明            │
  ├──────────┼───────────────────────────┤
  │ q        │ 待查询的词                │
  ├──────────┼───────────────────────────┤
  │ langType │ 语言类型（英中查询用 en） │
  ├──────────┼───────────────────────────┤
  │ appKey   │ 应用 ID                   │
  ├──────────┼───────────────────────────┤
  │ dicts    │ 词典名（英中用 ec）       │
  ├──────────┼───────────────────────────┤
  │ salt     │ 随机值（UUID）            │
  ├──────────┼───────────────────────────┤
  │ sign     │ 签名（SHA-256）           │
  ├──────────┼───────────────────────────┤
  │ signType │ v3                        │
  ├──────────┼───────────────────────────┤
  │ curtime  │ UTC 时间戳（秒）          │
  └──────────┴───────────────────────────┘

  响应字段（我们需要的）

  {
    "errorCode": "0",
    "result": [{
      "basic": {
        "phonetic": "音标",
        "us-phonetic": "美式音标",
        "uk-phonetic": "英式音标",
        "explains": ["释义1", "释义2", "..."]
      },
      "sentence": [{
        "sentence": "例句",
        "translation": "例句翻译"
      }]
    }]
  }

  签名生成（与翻译服务相同）

  sha256(appKey + input + salt + curtime + appSecret)
