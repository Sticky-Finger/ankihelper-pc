  统一流程：添加卡片前做了什么

  _addNoteToAnki 的调用链（results_list.dart:158）：

  读取当前模板 → ensureModelFields() 校验/注册 Anki 模型
               → buildFields() 按字段映射填值
               → addNote() 添加

  ensureModelFields（template_manager.dart:155）只关心一件事：「当前模板」在 
  Anki 里对应哪个模型名，它有 4 个分支：

  1. 模板 id == 'basic'        → 直接用 Anki 内置名 "Basic"，不检查字段（:160）
  2. Anki 里没有这个名称        → 用模板自带的 HTML 自动 createModel（:167）
  3. Anki 里有同名且字段匹配    → 直接用这个模型（:178）
  4. Anki 里有同名但字段不匹配  → 自动改名创建「原名-N」，返回
  wasRenamed（:183）

  第一个问题：Anki 没有这个模板，会怎样？

  自动注册，不用你手动建。 走分支 2（:167-174）：

  - getModelNames() 里没有 template.name → 调
  _registerToAnki（:224），用模板自身存储的 frontHtml / backHtml / css / fields
  调 createModel 建模型，然后用这个模型名 addNote。
  - 注意：创建用的 HTML 是模板对象里存的，不是重新读 assets 或文件。

  第二个问题：手动导入模板后再添加，会怎样？

  分两个阶段：

  导入时（best-effort，:98-106）：
  - importFromFile 解析 HTML 后会尝试 _registerToAnki 注册，但包在 try-catch
  里——Anki 没打开就静默跳过，不阻塞导入。模板照常存入本地并设为当前选中。
  - 所以导入时是否成功注册了 Anki 模型，不确定。

  添加时（兜底）：
  - 走同一个 ensureModelFields。
    - 如果导入时注册成功且字段没变 → 分支 3，直接用。
    - 如果导入时 Anki 没开、或模型被删了 → 分支 2，现在补注册。
  - 结论：真正保证 Anki 里有模型的是「添加卡片」这个动作，导入本身不保证。

  第三个问题：Anki 已有同名模板，但和本地不完全一样？

  这是重点，判断规则在 _fieldListsMatch（:213-221）：

  比较两个字段列表：先长度相等，再各自排序后逐项相等（忽略顺序）

  注意两点：

  1. 只比对字段名，不比对 HTML / CSS。 所以哪怕 Anki 里那个模板的正反面 HTML
  跟你本地完全不同，只要字段集合一致（个数 + 内容，顺序无所谓），就认为匹配 →
  分支 3，直接用 Anki 的模型添加。卡片按 Anki 里现有的 HTML 渲染，本地的 HTML
  被忽略。
  2. 字段不一致时自动改名（:183-199）：递增找
  原名-1、原名-2…直到名字可用，用新名字 + 本地 HTML 建模型。然后
  results_list.dart:177-185 检测到 wasRenamed 会：

  把本地模板名改成新名字并持久化（下次就直接命中新名，不再改名）；
