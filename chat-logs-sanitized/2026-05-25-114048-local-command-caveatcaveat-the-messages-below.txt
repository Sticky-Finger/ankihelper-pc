  手动导入的现有实现

  关键流程在 template_manager.dart:76-117 的 importFromFile：

  importFromFile(filePath, service)
    │
    ├─ 1. File(filePath).readAsString()        ← 从文件系统读 HTML
    ├─ 2. parseHtml(content)                   ← @@@ 分割为 4 段
    ├─ 3. 从文件名提取 name
    ├─ 4. id = 'imported_${毫秒时间戳}'          ← 本地唯一 ID
    ├─ 5. _buildDefaultMapping(parsed.fields)  ← 自动映射中文→英文 key
    ├─ 6. _registerToAnki(name, parsed)        ← best-effort 注册（try-catch
  包裹）
    │     └─ getModelNames() → 不存在才 createModel
    └─ 7. return CardTemplateModel{id, name, fields, mapping,
  frontHtml/backHtml/css}

  _registerToAnki 做的事很简单：查一下 Anki 里有没有同名模型，没有才创建。

  同时 TemplateProvider.importTemplate() 在导入后：
  - _templates.insert(0, template) → 插入列表首位
  - state = template → 设为当前选中
  - 持久化选中 ID 和导入路径到 SharedPreferences

  分析

  手动导入这个流程中，真正依赖 Anki 的只有步骤 
  6（_registerToAnki），而且它已经是 try-catch 忽略失败的了。步骤 1-5 和 7
  全部是纯本地操作。

  所以你刚才说的"跳过真实导入直接生成配置"，其实就是：

  1. 步骤 6 的 _registerToAnki 不在启动时调 → defer 到 ensureModelFields
  2. 步骤 1 的 File().readAsString() 换成 rootBundle.loadString()（从 assets
  读）
  3. 步骤 4 的 ID 从 'imported_时间戳' 改为
  'builtin_vocabulary_card_model'（固定 ID，因为它是内置的）
  4. 步骤 5 的 _buildDefaultMapping 改为从 .json 配置读取（而不是自动识别）

  唯一的格式问题：importFromFile 中 _buildDefaultMapping 返回 {模板字段名: 
  数据源key} 格式。.json 里按同方向写，读出来直接赋值，不需要翻转。这就是我上面
  那个问题问的——选第一个选项（与内存格式一致）就行。
