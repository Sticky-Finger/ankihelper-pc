     统一模板管理重构计划

     Context

     当前模板实现中存在多处硬编码问题：

     - CardTemplateModel 的字段列表、字段映射是 Dart 代码中的静态常量
     - TemplateManager.ensureModelExists 硬编码了 HTML 文件路径
     - TemplateManager.buildFields 用硬编码的 switch 语句做字段映射
     - HTML 文件有 4 段 @@@ 分隔（front/back/CSS/字段名），但解析器只分割出 3
     段，第 4 段被错误地拼接到 CSS 中

     目标：消除所有硬编码，建立统一的模板解析和管理机制，使内置模板和未来用户导
     入的模板共用同一套逻辑。

     ---
     模板文件格式规范

     HTML 模板文件（.html，4 段 @@@ 分隔）

     [正面模板 HTML，含 {{字段名}} 占位符]
     @@@
     [背面模板 HTML]
     @@@
     [CSS 样式]
     @@@
     字段名1
     字段名2
     ...

     配置文件（.json，与 HTML 同名同目录）

     {
       "name": "词汇卡片",
       "fieldMapping": {
         "word": "单词",
         "phonetic": "音标",
         "meaning": "释义",
         "example": "例句",
         "exampleTranslation": "例句翻译"
       }
     }

     - name：模板在 Anki 和 UI 中的显示名称
     - fieldMapping：应用字段名 → 模板字段名的映射（无法从 HTML
     自动推断，需要显式声明）
     - 内置模板：assets/template01/vocabulary_card_model.html + .json
     - 用户导入模板：后期需同时提供 .html 和 .json 两个文件

     Step 3: 重写模板管理器

     lib/services/template_manager.dart：

     parseHtml(String html) — 统一解析器：
     - 按 @@@ 分割为 4 段：front、back、css、fieldsText
     - 第 4 段按换行 trim 后得到字段名列表
     - 返回 {front, back, css, fields}

     loadFromAssets(String basePath) — 从 assets 加载模板：
     - 读取 {basePath}.html → parseHtml
     - 读取 {basePath}.json → 解析 name + fieldMapping
     - 组装为 CardTemplateModel，id 从文件名提取

     ensureModelExists(service, template) — 注册到 Anki：
     - basic 模板跳过（Anki 自带）
     - 调用 modelNames 检查是否已存在
     - 不存在则调用 createModel 注册，使用解析出的 front/back/css/fields

     buildFields(template, entry) — 动态构建字段：
     - 新增 CardEntryModel.toMap() 方法返回 {'word': value, 'phonetic': value, 
     ...}
     - 遍历 template.fieldMapping，从 entryMap 中取值
     - 只添加非空字段

     Step 4: 重构模板 Provider

     lib/providers/template_provider.dart：

     启动流程（build() 中执行）：
     1. 加载内置模板：TemplateManager.loadFromAssets('assets/template01/vocabula
     ry_card_model')
     2. 自动导入到 Anki：TemplateManager.ensureModelExists(service, template)
     3. 从 SharedPreferences 恢复上次选中的模板 ID
     4. 暴露 presetTemplates 列表：[内置词汇卡片, basic 基础卡片]

     - 作为 Anki 自带模板，始终出现在列表中
     - 不需要 assets 文件，id 固定为 'basic'，name 为 '基础卡片'

     Step 5: 确认 pubspec.yaml

     确保 assets/template01/ 路径声明正确，Flutter 能打包 .json 文件。
